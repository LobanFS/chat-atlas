# Обновление 0.2.0

Одобренный второй вариант интерфейса стал основной версией проекта.

- Имена из JSON по умолчанию. Идентичность — `from_id`, подпись — последнее известное `from`. Ручные подписи не меняют привязку. При отсутствии ID остаётся fallback по имени с предупреждением. Для ручной проверки отмечен автор последнего сообщения экспорта.
- Карточки людей вместо трёх индексов. Видны количество/доля сообщений, слова, реплики, начала диалогов и медианное время ответа.
- Основной график: сообщения, слова, начала диалогов; общий объём, линии по людям, доли; 1/7/14/28 дней сглаживания, по умолчанию 7.
- Темп за 7/14/28 дней против предыдущих 28, отдельно по всей переписке и по каждому человеку. Абсолютные изменения и оба средних показаны рядом с процентами.
- Исторический рост и спад выбираются из недельных проверок по абсолютной разнице сообщений/день. Не выдаются за вывод о причинах и чувствах.
- Отдельная визуальная зона динамики, контрастный общий темп и цветные карточки людей. Переключатели остаются рабочими в автономном HTML.

Локальные отчёты в `.private/` исключены из Git. Демо и тесты используют синтетические данные.
