# Публикация обновления

Репозиторий: [LobanFS/chat-atlas](https://github.com/LobanFS/chat-atlas). Удалённый репозиторий уже настроен как `origin`; создавать его повторно не нужно.

Для отправки подготовленных коммитов основной ветки:

```sh
cd ~/projects/chat-atlas
git switch main
git pull --rebase origin main
git push origin main
```

Если `pull` сообщает о конфликте, сначала разрешите его и завершите rebase, затем выполняйте `push`. Принудительная отправка не нужна.

## Авторство

Проверьте автора и содержимое ещё не отправленных коммитов:

```sh
git log origin/main..main --format='%h %an <%ae>%n%B'
git diff --stat origin/main..main
```

Коммиты используют локальное Git-авторство пользователя. В них нет `Co-authored-by`, отдельного AI-автора или bot-аккаунта. Email автора должен быть привязан к вашему аккаунту GitHub.

## Следующие изменения

После редактирования исходников выполните `npm test` и `npm run build`, проверьте изменения через `git diff`, добавьте нужные публичные файлы в индекс и создайте коммит. Затем повторите команды отправки выше.

Публикуются исходники, тесты, документация, MIT-лицензия и автономная сборка `dist/index.html`. Синтетическое демо не содержит реальную переписку. Экспорты, личные отчёты и QA-артефакты исключены из Git.

Пользователи могут скачать `dist/index.html` через Raw/Download и открыть локально. GitHub Pages или иной хостинг для работы не требуются.
