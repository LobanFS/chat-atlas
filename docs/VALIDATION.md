# Проверка версии 0.3.0

Проверено 26 сентября 2026 года.

- 81 автоматический тест: прежние расчёты 1:1, группы, фильтры, стабильные идентификаторы, явные ответы, смех, все режимы HTML и CLI.
- Независимый Python-пересчёт реального группового экспорта: совпали все авторские объёмы, начала сессий, реплики, активные дни, ночные сообщения, реакции, ответы, смех, медианы ответов, дневные ряды, направленные пары и сессии.
- Проверка 30 авторов подтверждает сохранение суммы при сворачивании остальных участников на графике. Нагрузочный smoke движка на 5 000 авторах использует разреженные ряды и связи без квадратной матрицы.
- Chrome с отключённой сетью: загрузка JSON, четыре режима отчёта, типы графиков, 1/7/14/28-дневное сглаживание, выбор участников, периоды сравнения, поиск, сортировка, смена порога, фильтр дат, слова и эмодзи, переименование и анонимизация. Ошибок JavaScript и HTTP-запросов не обнаружено.
- Скачанный HTML открыт отдельно без сети: настройки графика и выбора участников сохранены; поиск и сортировка работают; сохранённый поисковый запрос виден и его можно очистить.
- Реальные личный и групповой отчёты открыты в Chrome с именами. На ширине 390 px горизонтального переполнения страницы нет; проверен режим печати без обрезки прокручиваемых таблиц по высоте.
- Визуальное ревью несколькими агентами: desktop 1440 px и mobile 390 px. Исправлены мобильная таблица участников, перенос анонимных подписей, округление положительных микродолей и контраст тепловой карты. Числа и имя участника видны без горизонтальной прокрутки основного обзора.
- Синтетические демо 1:1 и группы запускаются из приложения. Скриншоты в README содержат только синтетические данные. Частные отчёты исключены из Git.

Ограничения: Safari и Firefox в этой итерации не проверялись. 200 МБ — защитный лимит загрузки, а не размер нагрузочного испытания. Интерфейс проверен на небольшом групповом чате и синтетических наборах; технический тест 5 000 авторов не является оценкой удобства такой группы в браузере. Полноценная печать PDF не входит в результат; проверялся print media.

## Предыдущая проверка версии 0.2.0

Браузерная проверка выполнена 24 сентября 2026 года. Автоматические тесты и сборка повторно проверены 26 сентября 2026 года при подготовке основной версии.

- 66 автоматических тестов: нормализация, даты/часовые пояса/DST, фильтры, дубликаты, порог сессий, медианы/P90, индексы, качество данных, 46k synthetic workload, режимы, CLI, опциональная лексика и escaping HTML.
- Локальное открытие `dist/index.html` по `file://` в установленном Google Chrome; весь сквозной тест выполнялся с отключённой сетью. Ни одного HTTP-запроса или ошибки JavaScript.
- CLI проверен на временных синтетических данных, включая отказ от перезаписи входного JSON через symlink/hardlink и явные флаги имён/лексики.
- Переключатель лексики проверен в браузере; при выключении таблицы и ссылка навигации исчезают.
- Демо и реальный экспорт порядка 46 тысяч сообщений. Счётчики, сессии, инициаторы, числа ответов и медианы дополнительно сопоставлены с независимым пересчётом на Python.
- Проверены четыре режима, смена порога, часового пояса и диапазона дат, повторная загрузка, восстановление после ошибки.
- Некорректный диапазон скрывает прежний результат и блокирует его скачивание, пока новый расчёт не завершён успешно.
- Некорректный JSON показывает фиксированное сообщение без фрагментов исходного файла. HTML в именах выводится как текст.
- Скачанный отчёт открыт отдельно без сети. Имена и ID реальных участников отсутствуют при включённой анонимизации; сырые сообщения и ID не включены; встроенный локальный JavaScript обслуживает графики из агрегатов.
- Итеративная визуальная проверка desktop (1440px) и mobile (390px), а также print media. На мобильной странице нет горизонтального переполнения; широкие графики имеют явную подсказку прокрутки и табличную альтернативу.
- В README показаны только синтетические данные. Реальный экспорт и частные QA-артефакты не включены в репозиторий.

Проверка в Chrome не заменяет полноценную матрицу браузеров: Firefox/Safari отдельно не испытывались. Печать проверена в режиме print media, PDF не является отдельным результатом этой версии. Максимальный объём 200 МБ — защитный лимит загрузки, а не заявление о нагрузочном испытании на таком объёме.

Интерфейс 0.2.0: проверены имена по ID, редактирование/сброс подписей и приоритет анонимизации, 3 показателя × 3 вида графика, окна сглаживания и сравнения, сохранение настроек в скачанном HTML и его переключатели без сети. Desktop 1440px и mobile 390px осмотрены.
